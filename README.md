# คลินิกหมอดาว · หน้าคิว (LIFF)

Static patient queue page for the clinic's LINE queue system, served by GitHub Pages.

- `index.html`, `privacy.html`: copied from the private code repo (`liff/`). Don't edit them here; edit them there and copy them over.
- `config.js`: this site's settings (`LIFF_ID`, `GAS_URL`, `OA_ID`). None of them are secrets.

Contains no secrets and no patient data.
